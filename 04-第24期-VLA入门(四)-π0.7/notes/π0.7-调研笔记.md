- 一句话: 在 π0.6-MEM 架构上把 prompt 从一句话扩成多模态"上下文"——subtask 文本 + 世界模型生成的多视角子目标图 + 速度/质量/失误元数据 + 控制模式——从而能把示范、失败、RL rollout、人类第一视角视频等混杂数据一起训；一个 5B 通用模型零样本追平 π*0.6 的 RL specialist，在未见厨房跟随开放指令约 87%，把叠衣服零样本迁移到从未叠过衣服的 UR5e（与专家遥操作员的零样本水平相当），并能被人用语言"教会"新任务。

## 1. 要解决的问题

此前的 VLA 缺少 LLM 那种组合泛化：不仅做不了新任务，连训练过的任务往往也要任务专属微调才流畅（π*0.6 就是靠 RL specialist）。想用更大更杂的数据（不同策略、不同质量、失败、自主数据、人类视频）来换泛化，但朴素训练会把不同模式平均掉、被低质量数据拖累——Fig. 18 左图直接证明了这一点。类比图像/视频生成里的 prompt expansion：给每条数据配上"做什么 + 怎么做 + 做得怎样"的详细上下文，让模型学会分辨模式，测试时再用 prompt 把它"拨"到高质量模式。有些信息语言说不清（叠好的衬衫长什么样）或很微妙（整段质量），所以要加子目标图和元数据。

## 2. 方法

**架构（Sec. IV、VI-B，Fig. 2）。** 约 5B：Gemma3 4B VLM（含 400M 视觉编码器）+ 860M flow action expert。视觉编码器沿用 MEM 的 video history encoder：最多 4 路相机（前、双腕、可选后视），每路最多 6 帧历史（步长 1 s，整段历史以 0.3 概率 dropout，后视也 0.3），压缩成与单帧相同的 token 数；最多 3 张子目标图走同一编码器；分辨率 448×448。block-causal 注意力：观测 token 与子目标 token 各自双向，子目标可看观测，之后的文本 token 因果。本体状态（含历史）线性投影成 token。action expert 用 adaptive RMSNorm 注入 flow 时间步，固定 50 个动作 token，双向互看并看 backbone 激活。KI 配方：backbone 用 FAST token 监督，expert 梯度不回流。训练时的 RTC：训练时模拟 0–12 步延迟（50 Hz 下最多 240 ms），推理无额外开销。

**上下文 C_t 的四种成分（Sec. V）。** (1) subtask 指令 ℓ̂_t（沿 π0.5），推理时由学到的高层策略或人给出——后者即"verbal coaching"，而 coaching 记录可以反过来训练该任务的高层策略；(2) 多视角子目标图 g_t：由一个"轻量世界模型" g_ψ 生成，它从 BAGEL（14B mixture-of-transformers 图像理解/编辑/生成模型）初始化，用 flow matching 损失预测段末帧，训练数据是高质量分段标注的机器人数据 + 第一视角人类视频 + 网页图像编辑/视频数据，这样网页/人类视频里的语义和物理概念可以经由子目标图迁移进策略；(3) 元数据 m：整段速度（按 500 步分箱）、整体质量 1–5、当前段是否失误（人工粗标）；(4) 控制模式 c ∈ {joint, ee}。完整 prompt 形如 `<观测><子目标> Task: peel vegetables. Subtask: pick up the peeler. Speed: 8000. Quality: 5. Mistake: false. Control Mode: joint.<本体>`。

**Dropout 与子目标采样（Sec. V-E、VI-C）。** 有子目标图时动作预测退化成 inverse dynamics、学得太快，所以只有 25% 的样本带子目标图；其中 30% 再去掉 subtask 文本；元数据整体 15% 丢弃、各分量再各 5%；控制模式不丢。真实子目标图 25% 取段末帧、75% 在未来 0–4 s 均匀采；另外大量用世界模型生成的图构造训练样本以缓解真/假图的分布偏移。

**数据（Sec. VI-A）。** 多平台多环境（实验室、仿家、真实家庭）的示范；大量策略评测产生的自主数据（含 π*0.6 RL 训练时的 rollout 和失败）；rollout 中的人类干预；开源机器人数据；第一视角人类视频；网页定位/属性/VQA/纯文本；机器人与网页视频的视频描述。泛化评测任务的自主数据被排除。

**推理（Sec. VII，Alg. 1）。** 元数据固定为：速度 = 该任务 episode 长度的 15% 分位，质量 5，失误 false；子目标图在 subtask 改变或 Δ=4 s 时异步刷新；5 步去噪出 50 步 chunk，执行 15 或 25 步；可对元数据做 CFG，β ∈ {1.3, 1.7, 2.2}。单张 H100：最小配置（3 相机、5 步、训练时 RTC）38 ms，开启 MEM 编码器和子目标图最坏 127 ms；世界模型在 4×H100 张量并行 + 8 bit 量化 + SageAttention 下 25 步生成一张子目标约 1.25 s（Appendix C）。

**机器人。** 移动双臂、轻量静态双臂 "BiPi"、双臂 UR5e + Robotiq（跨 embodiment 测试，20 Hz，臂更长更重、装在桌两侧）、单臂；其余 50 Hz；PD 控制，末端模式用数值 IK。

## 3. 实验

**开箱即用的灵巧任务（Sec. IX-A，Fig. 6/7）。** 与 π*0.6 的 RL specialist 比（成功率 + 相对 throughput，估读）：laundry T 恤两者持平（成功率 ≈95% vs ≈93%）；diverse laundry throughput ≈1.45×、成功率 ≈72% vs ≈68%；espresso throughput ≈0.9×、成功率均 ≈93%；box building throughput ≈1.45×、成功率 ≈85% 持平。与 π0.6 SFT specialist 比（花生酱三明治、T 恤翻面、开门驶入、切西葫芦、削皮、换垃圾袋），task progress 大体持平（估读差距在 ±10 点内）。消融（Fig. 7）：去掉元数据或去掉自主评测数据都显著变差，box building 的相对 throughput 从 1.0 掉到 ≈0.22（no metadata）/ ≈0.57（no eval data），espresso 成功率从 ≈95% 掉到 ≈50%/≈60%。记忆任务（Fig. 8）：零样本与 π0.6-MEM 微调 specialist 相当或更好（swap 3 mugs ≈100% vs ≈88%）。

**指令跟随（Sec. IX-B）。** 14 个场景、每个 3–6 条开放指令、4 个未见厨房 + 2 个未见卧室（Fig. 9）：指令成功率估读 π0.5 ≈28%、π0.6 ≈55%、π0.7 ≈87%（厨房）；卧室 ≈25/55/73%。复杂指代（"拿我用来喝汤的东西""最大盘子上的水果"，Fig. 10）：π0.5 ≈18%、π0.6 ≈15%、π0.7 ≈32%、π0.7+子目标图（GC）≈63%。逆数据偏差（Fig. 11）：Reverse Bussing（垃圾进餐具箱、餐具进垃圾桶）π0.5 ≈50%、π0.6 ≈35%、π0.7 ≈82%；Reverse Fridge→Microwave 只有 π0.7(GC) 能做（≈70%，其余 ≈0–3%），子目标图是关键。

**跨 embodiment（Sec. IX-C，Fig. 12）。** 简单重排任务上三代模型都能迁移；embodiment 差距越大 π0.7 优势越大：Shirt Bagging（静态双臂数据 → 单臂 UR5e）估读 ≈55/65/92%。灵巧任务：UR5e 上从未采过叠衣数据，towel folding π0.5 ≈5%、π0.6 ≈42%、π0.7 ≈58%、GC ≈78%；shirt folding ≈3/38/67/85%。人类研究（Appendix F）：10 名经验前 2% 的遥操作员（平均 375 小时）首次在 UR5e 上叠衬衫，task progress 90.9%、成功率 80.6%；π0.7(GC) 为 85.6% / 80%。模型还自发换了策略（源机器人斜向抓布，UR5e 上改用竖直抓取；单臂 pick-place 代替双臂撑袋，Fig. 13）。

**组合泛化与 coaching（Sec. IX-D）。** 未采集数据的短程新任务（压法压壶、舀米、擦耳机、转风扇）可直接做（Fig. 17）；长程新任务（气炸锅装/卸红薯、烤百吉饼）靠人逐步语言 coaching：Fig. 15 估读 loading air fryer π0.5 ≈10%、π0.6 ≈22%、π0.7 ≈97%；toasting bagel ≈25/45/45%、GC ≈78%。用 coaching 记录训高层策略后，全自主版本与 coaching 版本接近（Fig. 16），不需要任何遥操作动作数据。

**数据规模与质量（Sec. IX-E，Fig. 18）。** 按质量/速度把 T 恤数据分成 top 30/50/80/100%：有元数据的模型 throughput 估读从 ≈12 涨到 ≈23 次/小时，无元数据的从 ≈11 降到 ≈9——低质量数据在有元数据时是养分、没有时是毒药。去掉最多样的 20% 数据比随机去掉 20% 在新任务上差得多（例如 spinning ≈5% vs ≈48%）。

## 4. 局限

作者承认（Sec. X）：未见任务或未见任务-机器人组合成功率只有 60–80%，而已见任务 90%+；数据太大太杂，很难界定什么是真正"未见"，泛化可能主要是"重混"已有技能。我读出来的：(1) 元数据、分段标注、失误标注都是人工成本；(2) 世界模型 14B、4×H100、1.25 s/张，系统复杂且昂贵；(3) 复杂指代没有子目标图时只有 ≈32%，语言理解仍是短板，靠世界模型"翻译"成图像补救；(4) 评测多为 PI 自己的任务与 rubric，试验次数未在正文说明；(5) 不开源。

## 5. 复现要点

- 未开源；5B 策略 + 14B 世界模型 + 高层策略，推理需 1 张 H100（策略）+ 4 张 H100（世界模型）。
- 若只复现"元数据条件化"思想：在开源 π0.5 上给数据加速度/质量/失误标签并写进 prompt，训练时按 15%/5% dropout，推理时取 15% 分位速度、质量 5——方法与架构无关，8×H100 可行。子目标图条件化可用 SuSIE 式的开源图像编辑模型替代 BAGEL。
- 关键超参：历史 6 帧/1 s、dropout 0.3；子目标图 25% 样本、subtask 30% dropout；元数据 15%+5%；子目标 25% 段末/75% 0–4 s；训练时 RTC 延迟 0–12 步；推理 5 步去噪、执行 15/25 步；CFG β 1.3–2.2；子目标刷新 4 s。
- 坑：带子目标图的样本比例不能高，否则退化成 inverse dynamics；元数据要覆盖足够的质量/速度多样性才学得到相关性；真/假子目标图要混训。
