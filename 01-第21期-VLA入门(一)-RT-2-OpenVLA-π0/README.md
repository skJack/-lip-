# 第 21 期 · VLA 入门（一）

**视频标题**：机器人大模型 VLA 入门：从 Google 的 RT-2 到 Physical Intelligence 的 π0，三篇论文讲清动作是怎么输出的

VLA 是什么、模型每一步的输入输出、一条机器人数据长什么样；RT-2 把动作当文字 token、OpenVLA 把这条路开源、π0 用 flow matching 一次出 50 步动作块。
