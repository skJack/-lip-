### 第 13–14 页 计算图与决定位置（反推，Hume）
- token 可加：1 道 yes/no 268 token、2 道 276；「noul + 2 选项 choice + 2 档 score」318。
- 上限：单分支（state + 一题）≈ 32,768，整请求 ≈ 65,536；23k state × 5000 题能过。
- 隔离：`ZEBRA-7741` 在兄弟问题 0.00，在 state 0.90–0.92，五次重复；删掉兄弟问题仍 0.00。
- listwise：参考卡片放选项开头 12/16（平均 0.50）、中间 11/16（0.49）、末尾 16/16（0.89）、放 state 48/48（1.00）；加无关第五项 log-odds +0.38 → +0.11（配对 CI −0.36 到 −0.19，10 个随机块）；顺序反转 0.84–0.89 → 0.93–0.96；重复条件被瓜分。
- 假选项：105 次请求、7 种分隔符，无法冒充。
- output_tokens：随 ID 长度与选项数变，不随概率值变；255 选项回复报 2714 个输出 token，延迟与 2 选项相同。
- 读出头四个候选：末位置线性头（256 槽）、pointer（200 选项复制测试正确答案任意位置 1.00、错误不外溢）、词表头 K 行（假选项实验不利）、约束解码（官方说「不同输出路径」排除）。
- kev 复现的布局与 mask：`<state> … <q> instr <opt>…</opt> … <decide>`；attention-only 用 mask，Gated DeltaNet 每题单开一行、位置编码从 state 末尾重数；两种方式概率差 4e-6。

### 第 15 页 三种头

### 第 19 页 训练（罚分曲线页已删，算例留档）
- 全称：RLHF = Reinforcement Learning from Human Feedback；RLVR = Reinforcement Learning with Verifiable Rewards；RLCD = Reinforcement Learning for Calibrated Decisions（TypeSafe 自创）。
- 官方原句："trained for calibrated decisions: their probabilities are optimized against outcomes to reflect uncertainty"；"calibration is measured across groups of predictions; it does not guarantee that an individual answer is correct."
- mode dropping、「confident-sounding hallucinations」：docs AI primer。
- HN 上对 RLCD 的解释（sothatsit）："massively negatively reward {yes:0.9,no:0.1} if the answer was no, and less negatively reward {yes:0.6,no:0.4}"。
- 罚分表（log score，真实比例 0.6）：报 0.50 → 0.693；0.60 → 0.673；0.80 → 0.778；0.95 → 1.229；0.99 → 1.848；1.00 → ∞。推导：E = −[q ln p + (1−q) ln(1−p)]，dE/dp = 0 ⇒ p = q。
- 0/1 奖励期望 = p_正确，线性，最大在 p = 1。
- Brier 1950（Monthly Weather Review）给降雨预报打分；Brier = Σ(p_i − y_i)²；Jev 用 log 还是 Brier 官方未说。Laya 公开配方：log + spherical + ranked probability score，高斯噪声探索，组内平均 advantage，TD(λ=1)。open-jev 的 RLCDLoss：软目标 NLL + Brier + 一致性 + 置信度惩罚 + ECE。
- 「单步、标签已知时退化成换 loss 的监督学习」是本期的说明。
- 与 OpenAI 2025-09《Why Language Models Hallucinate》（评测只奖励答对不奖励弃权）的联系是本期的类比，稿子没用。

### 第 34–38 页 PaperDance（我自己的产品，2026-09-21 的实测）
- 现状：召回用全文检索加向量相似度，相关性是词面分和余弦的加权；严格模式下人脸这个方向的相关率 55%。
- 规模：25 万篇；每工作日约 450 篇新论文；159 个方向。
- 实验一（视频生成 + 人脸，54 篇，人工标注）：A1 AUC 0.995、sub AUC 1.000、阈值 0.5 P 1.00 / R 0.82；A2 0.997；Choice 版概率坍缩不能用；纯中文 0.924 且核心 T2V 论文 0.14–0.25；仅英文检索词 0.995；20 篇一页 1.03 / 0.98 / 0.34 s，9.2k token，$0.0004，三次最大偏差 0.06。漏的 3 篇 0.38–0.42。
- 实验二（医疗 LLM KV cache 压缩，5 细分，54 篇）：378 问一次请求 2.3 s、56.9k token、$0.0024；AUC 0.979；阈值 0.5 召回 1.00 精确率 0.82；同词异义 GNN PTQ 0.04、骨架 quantization 0.04、扩散 step pruning 0.05；细分 13 篇 10 篇一致。
- 实验三（红心 / 收藏当口味）：AUC 0.60。
- 线上仿真（8 方向 × 100 张，800 篇 $0.017，评审 qwen3-max）：表见 PPT 第 24 页；Jev 只看前 1200 字符；评审口径坑（细分不是过滤条件）；direction_en 坑（领域是偏好不是硬条件）。对比视频见视频正片。
- 重排：基础分乘以相关概率（严格模式 rel < 0.5 丢、探索卡 rel < 0.3 丢）；≤ 40 篇 / 请求；超时 + 熔断 + 缓存 + 后台开关；固定 jev-1.13.0。
- 成本：当前规模一个月一百块左右。
