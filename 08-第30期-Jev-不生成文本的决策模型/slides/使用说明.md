# 第 28 期 · Jev · HTML PPT 使用说明

打开方式：用 Chrome 直接打开 `deck.html`（双击即可，图片是本地文件）。操作和前几期完全一样：

- `→` `空格` `↓` 下一页；`←` `↑` 上一页；`Home` `End` 首尾页
- **左上角**：鼠标移过去显示 `‹ 页码 ›  ☰`——左右箭头翻页，`☰` 展开全部页面列表点选跳转；`G` 键同样展开
- `F` 全屏；`C` 显示或隐藏左下角页码；直接敲数字跳页
- 鼠标点击右侧 80% 区域下一页，左侧 20% 上一页
- 地址栏 `deck.html#10` 直接打开第 10 页；`deck.html?nav=1` 打开时展开页面列表
- **视频页**（6、31、32、37）：仓库里不放视频文件，这四页换成了截图；官方 demo 的原片在 TypeSafe 发布文里

**风格**：和 27 期一样，浅灰底 + 黑字 + 单一蓝色强调，一页一张图加一个标题，没有底部注释、没有出处小字；出处全在 `../notes/技术事实核查.md`。第 7 页是接口（输入输出格式），第 8 页是原样的请求 / 返回 JSON（两块代码卡），第 9 页按你的要求放了一个例子（中文工单，官方 API 实测）；每一段前面有一页过渡页（编号 + 两个字）。

**自绘的页**（都是 SVG，在白卡里）：
