# 世界模型 · 第 4 期 · World Action Model · HTML PPT 使用说明

打开方式：用 Chrome 直接打开 `deck.html`（双击即可，图片都是本地文件，不需要联网）。操作和前三期完全一样：

- `→` `空格` `↓` 下一页；`←` `↑` 上一页；`Home` `End` 首尾页
- **左上角**：鼠标移过去显示 `‹ 页码 ›  ☰`——左右箭头翻页，`☰` 展开全部页面列表点选跳转；`G` 键同样展开
- `F` 全屏；`C` 显示或隐藏左下角页码；直接敲数字跳页
- 鼠标点击右侧 80% 区域下一页，左侧 20% 上一页
- 地址栏 `deck.html#21` 直接打开第 21 页；`deck.html?nav=1` 打开时展开页面列表

**这期没有动画页**（第 3 期第 22 页那种 `J`/`K` 走步的页面这期没用到），所以模板里的动画那套 JS 已经删掉了。

**风格**：和前三期一样是苹果风，一页一张图加一个标题，**没有底部注释行**（沿用第 3 期起的做法）。
出处全写在 kicker 里（`· 论文图 4`、`· 自绘`、`· 口径取自 …`），页面上只有小标、标题、主体。
**页面上一个比喻都没有**——分镜 / 副科 / 底片 / 填空题 / 导航重新定位 / 菜单下架 / 开完会各回各办公室，全在口播稿里。
全部 54 页，段落顺序是 01 什么是 WAM / 02 这条线 / 03 铺垫 / 04 DreamZero / 05 LingBot-VA / 06 VA 2.0 / 07 悬案 / 08 局限 / 09 小结，
段数多，所以每个主段前面加了一页 `.divider` 过渡（第 2、7、14、33、41 页）。

## 自绘的页（都是 SVG，在白卡里）

- **第 15 页「这个词是 DreamZero 起的」（DreamZero 那一段的第一页）**：arXiv 上摘要含 "world action model" 的论文月度柱状图（2025-09 → 2026-08，
  0/0/0/1/0/2/7/9/21/46/36/64），2026-02 之前的柱子是灰的、之后是蓝的，箭头标在 2026-02 那根上。
  下面配一张原话卡（为什么叫 World 不叫 Video）。数字出处见 `../notes/技术事实核查.md` 第 0 节。
- **第 6 页和第 53 页是同一张总图「动作从模型外面走进模型里面」**：五行五拨工作，从左到右条件 → 模型 → 输出，蓝框是动作，
  蓝框的位置就是这期的主线。第 53 页的内容是 JS 从第 6 页复制过来的（`#recap` 那段脚本），**改第 6 页就够**。
  GR-1 那一行的两个输出（未来帧、动作）是**两条分开的箭头**：上面一条进未来帧、下面一条绕过未来帧的下沿进动作框——
  早先画成一条穿过未来帧的虚线，看起来像「未来帧变成动作」，意思反了，已改。
- **第 17 页「联合分布 = 视频预测 × 逆动力学」**：上面是论文式 1 的三块，下面是 UniPi / DreamZero 两行对照 + 一句蓝底的「换句话说」。
- **第 20 页「误差累积 vs 被现实校正」**：上半条是纯视频生成一段接一段往下画（框越来越红），下半条是 WAM 想一段执行一段、
  真画面写进 KV cache。这页是第 18 页那条绿线（Update with Real Observation）的展开。
- **第 21 页「走一遍（上）」**：上半是两条错位的时间轴（机器人 15 Hz 连续执行 / 模型每 1.6 秒醒一次算 0.6 秒），
  下半是第一次调用的三步卡片。**错位是故意的**——模型算第 1 块的时候机器人正在执行第 0 块，这页要讲的就是这个。
- **第 22 页「走一遍（下）」**：左上「上一轮想象的是…现实是…」，右上「这一刻发生了什么」，下面是 t=0/1/2 的 cache 内容表，
  右边一个浅红卡片放两种清空记忆的情况。
- **第 26 页「采满 50 段就下架」**：四步流程（打印清单 → 一段三任务 → 采满 50 段废除 → 被迫提新任务）+ 三个大数字（22 / 30.5 万 / 244）
  + 一句和 DROID、Bridge 的对比。
- **第 46 页「数据」**：上面一行三阶段课程（文生图 → 文生视频 → 具身适配，第三块蓝底），中间一条蓝色分叉线把阶段三展开成
  三块数据（机器人 / 人类第一视角 / in-context），下面一条灰线隔开，三栏讲三个特点，第 03 栏（人手怎么对齐夹爪）蓝底高亮。
  数字出处见 `../notes/技术事实核查.md` 第 7 节「数据」。
- **第 35 页「双流 MoT」**：两条竖流（视频 3072 维 / 动作 768 维），中间一条蓝色横条是联合自注意力。
  **画的是论文版**，不是开源那个 shared backbone 版（开源版只有一套 blocks），这一点写在 `../notes/技术事实核查.md` 第 6 节。
