# 世界模型 · 第 3 期 · Cosmos · HTML PPT 使用说明

打开方式：用 Chrome 直接打开 `deck.html`（双击即可，图片都是本地文件，不需要联网）。操作方式与前两期完全一样：

- `→` `空格` `↓` 下一页；`←` `↑` 上一页；`Home` `End` 首尾页
- **左上角**：鼠标移过去会显示 `‹ 页码 ›  ☰`——左右箭头翻页，`☰` 展开全部页面列表点选跳转；`G` 键同样展开列表
- `F` 全屏；`C` 显示或隐藏左下角页码；直接敲数字跳页；第 22 页 `J` / `K` 控制动画步骤
- 鼠标点击右侧 80% 区域下一页，左侧 20% 上一页
- 地址栏 `deck.html#10` 直接打开第 10 页；`deck.html?nav=1` 打开时展开页面列表；`deck.html?anim=5#22` 直接打开动画页的第 6 步

**风格**：和前两期一样是苹果风，一页一张图加一个标题。**底部那行注释（`.note`）整个去掉了**，页面上只有小标、标题、一张图；图卡的高度因此比第 2 期多出约 70px，白卡 padding 30px；出处全在 `../notes/技术事实核查.md`。页面上没有例子，抓苹果、传话、人拿杯子这些例子都只在口播稿里。

**自绘的页**（都是 SVG，在白卡里）：
- 第 3 页和第 41 页是同一张总图「动作在哪进出」：五行五篇，从左到右条件 → 模型 → 输出，蓝框是动作。第 41 页的内容是 JS 从第 3 页复制过来的，改第 3 页就够。
- 第 15 页「Cosmos 1 数据」：上面一行五步清洗管线和数量，下面是 2000 万小时原始视频的内容配比（论文 3.1 节的九个百分比），蓝色那条是手部动作与物体操作。
- 第 20 页「动作块怎么变成一个 latent 帧」：动作块 → 归一化 → 拉平 → 复制填满 → 覆盖占位帧，下面一行是读出。
- 第 22 页 **动画**：Cosmos Policy 规划模式 best-of-N，不自动播放，翻到这一页停在第 1 步，按 **J** 走下一步、**K** 退一步（到第 6 步再按 J 回到第 1 步），右侧对应的步骤高亮，图里的元素按步骤点亮（`svg[data-anim]` + `PH` 表驱动，和第 2 期第 16 页同一套实现）。
- 第 31 页「一个模板管所有任务」：Cosmos 3 的序列模板 + 四种模式（图生视频 / FD / ID / policy），token 行是 JS 按 `rows` 表生成的，实心 = 干净条件、虚线 = 加噪目标。
- 第 33 页「训练流程」：语言塔一行、生成塔一行。
- 第 35 页「推理」：上面五步（语言塔读指令 → 拼扩散段 → 生成塔去噪 → 读出 → 执行）加闭环虚线，下面策略模式和视频模式各一行的去噪步数、CFG、硬件时延、输出。
- 白卡里的 svg 用 `.diagbox.pad svg{inset:0;margin:auto;width:calc(100% - 88px);height:calc(100% - 68px)}` 留边并居中；之前写成 `inset:34px 44px` 加 `width:100%`，右边距会被顶掉、图向右溢出 44px，第 15 页顶到边的框暴露了这个问题。
- 箭头的 `<marker>` 定义在 `#stage` 开头的一个 0×0 的全局 svg 里——放在某一页的 svg 里会因为那页 `display:none` 而在别的页失效，这是这期踩到的坑。
