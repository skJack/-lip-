## 第 4 页 相对动作：是什么

| 说法 | 出处 | 备注 |
|---|---|---|
| 相对动作：一整段动作都以「推理那一拍的状态」为原点 | UMI §III PD2.1（L331–340）：「a sequence of SE(3) transforms denoting the desired pose at t relative to the initial EE pose at t0」；Fig. 6 图注（L310–318）：「relative to the same current EE pose for each inference step」 | 已核 |
| 英文 relative action | UMI 原文叫 relative trajectory；LeRobot `docs/source/action_representations.mdx`「Relative Actions (used by OpenPI / pi0)」；GR00T N1.6 README「state-relative action chunks」（我的调研笔记） | 已核 |

| 左图：坐标系标定差 3 cm，绝对动作整段平移、杯子落在碟子外；相对动作从手出发、照样放上 | 自绘（`ac_figs.py` fig_rel_a），3 cm、轨迹、碟子位置都是编的 | 示意。UMI 实拍的绝对动作失败是「抓杯子时手在杯子边上来回晃、往一边偏」（Fig. 8(b) Absolute Action），不是这张图的样子，所以没用论文图 |
| 出处：UMI，2024，斯坦福宋舒然组 | arXiv 2402.10329（2024-02-15 首发）；作者单位 Stanford / Columbia / TRI，一作 Cheng Chi、末位 Shuran Song（paper.txt L3–5）；RSS 2024（我的调研笔记） | 已核。会议取自 我的调研笔记 |

## 第 5 页 相对动作：怎么做（分步）

| 说法 | 出处 | 备注 |
|---|---|---|
| 此刻 30°，绝对 31 33 36 40 45 → 整段减 30 → +1 +3 +6 +10 +15 | 编的数（`ac_figs.py` fig_rel_b） | 示意。写法同 LeRobot 文档的例子（current_state 45 → 46、47.5 … → +1、+2.5 …） |
| 整段减同一个当前状态 | openpi `src/openpi/transforms.py` L204–223 `DeltaActions`：`actions[..., :dims] -= np.expand_dims(np.where(mask, state[..., :dims], 0), axis=-2)`，整块减同一个 state | 已核 |
| 每步减上一步 = UMI 论文的 delta，要一路加回去，误差会累积 | UMI Fig. 6 图注「Delta action represents each action step relative to its immediate previous action, therefore accumulates error」；LeRobot 文档「To recover absolute positions you must sum all previous deltas, which means errors accumulate over time」 | 已核 |
| 每步多算 0.5° → 第 5 步差 2.5°；整段减每步只差 0.5° | 编的数，0.5 × 5 = 2.5 | 示意 / 推算（假设每一步都偏同一个方向） |
| 页面：「openpi 的 DeltaActions 做的是左边这种」 | openpi `config.py` L325–329 注释「pi0 models are trained on delta actions (relative to the first state in each action chunk)」；我的调研笔记口径提醒 1 | 已核。口径坑：openpi / LeRobot 嘴上的 delta = 整段减当前状态 = UMI 的 relative；UMI 的 delta 是每步相对上一步。视频里只说「UMI 论文管这种叫 delta」 |
| 夹爪不减，照样存 0 / 1 | openpi `config.py` L229–231 注释「Gripper dimensions will remain in absolute values」、L329「the gripper actions which are always absolute」；LeRobot pi0 / pi05 `relative_exclude_joints=["gripper"]`；GR00T 夹爪 `ActionRepresentation.ABSOLUTE`（我的调研笔记、调研笔记） | 已核。页面上夹爪那一行 1 1 0 0 0 是编的 |
| 「夹爪只有开、合两种，写成相对的没有好处」 | LeRobot 文档「gripper commands are typically binary (open/close) and don't benefit from relative encoding」；GR00T 注释「binary open/close works better absolute」（调研笔记） | 已核 |
| ALOHA 双臂 14 维，`make_bool_mask(6, −1, 6, −1)`：两臂各 6 个关节减、两个夹爪不减 | openpi `config.py` L232 `use_delta_joint_actions: bool = True`、L263–267；`transforms.py` L433 `make_bool_mask` | 已核 |
| 统计量要在减完之后算 | openpi `scripts/compute_norm_stats.py`：先跑 `data_config.data_transforms.inputs`（含 DeltaActions）再统计；LeRobot 文档 Note「apply relative conversion before normalization … relative action stats are required」，要先 `lerobot-edit-dataset --operation.type recompute_stats --operation.relative_action true` | 已核 |
| 拿 30°–70° 的绝对统计量：+1 → −2.45，整段全跑到 −1 外面 | (1 − 30) / (70 − 30) × 2 − 1 = −2.45；+15 → −1.75 | 推算（30°–70° 是编的） |
| 推理：先反归一化，再加回推理那一拍的状态 | openpi `policies/policy_config.py` L83–88 输出顺序 `Unnormalize` → data outputs（`AbsoluteActions` 被 push 在最前）；LeRobot 文档「model output → unnormalize → AbsoluteActionsProcessorStep → robot」 | 已核 |
| 整段都加同一个数 | `transforms.py` L226–243 `AbsoluteActions` 整块加同一个 state；LeRobot 文档「caches the state once per inference call and … applies it to every action」 | 已核 |
| 此刻 52° → 53 55 58 | 编的数 | 示意 |
| 开源：openpi ALOHA 配置默认开；LeRobot `use_relative_actions`、GR00T 有开关，默认关 | openpi `config.py` L232；LeRobot `policies/pi05/configuration_pi05.py` L70 `use_relative_actions: bool = False`（pi0 L55 同）；GR00T `ActionConfig(rep=ActionRepresentation.RELATIVE)`（我的调研笔记） | 已核。没进视频里的：LeRobot groot 的 `relative_exclude_joints` 默认是空列表（`configuration_groot.py` L339），夹爪也会被相对化，要自己写 `["gripper"]`；DROID 用关节速度时不开；`pi05_libero` 不再额外转（LIBERO 原始动作已是末端增量） |
| 证据：UMI 摆杯子各 20 次，相对 20/20 = 100%，绝对 5/20 = 25% | UMI §V（L406–411 Ours 20/20）、§V-A（L515–518：delta 16/20 = 80%，absolute 5/20 = 25%）；Fig. 8(c) | 已核。页面小字有每步相对 80%，视频里没念 |
| 页面小字：绝对低主要是坐标系标定误差 | UMI §V-A「likely due to inaccurate calibration between the SLAM and robot base coordinate frames」「theoretically … could approach that of relative trajectory with better calibration」 | 已核。我的调研笔记口径提醒 2：不能说成「绝对动作天生不行」，固定机位下 ACT、OpenVLA-OFT 用绝对关节角也做得很好 |
