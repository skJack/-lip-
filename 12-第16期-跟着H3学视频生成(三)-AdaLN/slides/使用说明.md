# 跟着 H3 学视频生成 · 第三期 · AdaLN · HTML PPT 使用说明

打开方式：用 Chrome 直接打开 `deck.html`（双击即可）。整份 deck 就这一个文件，图全是 SVG 现画的，没有图片文件，不需要联网。

按键和前两期一样（这个系列比仓库里 VLA、世界模型两个系列的 deck 早，按键不一样）：

- `→` `空格` `↓` `Enter` `PageDown` 或鼠标单击：下一步——**同一页里先一个个放出动画，放完才翻到下一页**
- `←` `↑` `PageUp`：上一步（先收回本页的动画，收完回到上一页）
- `Home` `End`：首页 / 末页
- **左上角有一排页码按钮**：平时几乎透明，鼠标移过去才显出来，点哪个跳哪页
- 画布固定 1280×720，按窗口等比缩放；全屏用浏览器自己的全屏（Mac `⌃⌘F`，Windows `F11`）

配色和第二期一样：紫色 = 文本，橙色 = 视频，绿色 = 音频（第 4 页那张表的三列）。

页码对应讲什么：

| 页 | 标题 | 内容 |
|---|---|---|
| 1 | 封面 | AdaLN |
| 2 | LayerNorm 的作用 | 几十层连算，数值范围逐层漂移 → LayerNorm 把每个 token 拉回均值 0、方差 1 → 再用 scale / shift 把抹掉的幅度补回来；普通 Transformer 里这两个是训练完就固定的常数 |
| 3 | AdaLN：三个调制参数 | 一个子层的完整流程：RMSNorm → ×(1+scale)+shift → attention / FFN → ×gate → 加回残差；gate 是残差支路的门控；三个参数都由噪声水平 t 生成、随去噪阶段变，每层 2 个子层 × 3 = 6 组，t 不拼进序列 |
| 4 | 二维参数表 | H3 独有：行 = 这一步序列里出现的噪声水平（视频 t、音频 t、参考帧 0.999），列 = 模态，9 个格子每格 6 组参数；每行按（噪声水平, 模态）查表——这是 50 层里唯一区分「每一行是什么」的机制，参考帧和目标视频就靠取不同的格子区分 |
| 5 | 13B 可预计算 | 生成调制参数的线性层 50 层合计 ≈ 13B（占 33B 的四成），输入只有 t；推理的 8 个 t 事先全知道，开跑前一次算完，13B 权重不用进显存，常驻的只有 19.3B 核心 + 几百 MB 缓存；训练时 t 随机，占不到这个便宜 |
| 6 | 本期带走 | LayerNorm、AdaLN、13B 预计算各一句 + 下期预告：位置编码 |

每个数字的出处（13B 怎么算出来的、缓存为什么只有几百 MB、为什么是 9 格不是 8 组）见 `../notes/技术事实核查.md`。
