## LayerNorm 页

| 表述 | 核查 | 出处 |
|---|---|---|
| 深层网络数值逐层漂移 → 爆炸/消失、梯度不稳 | ✅ | 归一化层的标准动机（LayerNorm, Ba et al. 2016；教科书级） |
| LN = 对每个 token 向量 (x−均值)÷标准差 → 均值 0 方差 1 | ✅ | LN 定义；H3 用的是 RMSNorm 变体（只除均方根、不减均值），口播讲 LN 通式，PPT 流程图里写的是 RMSNorm，口径不冲突 |
| 归一化抹掉幅度信息 → 可学 scale(γ)/shift(β) 恢复表达 | ✅ | LN 原论文的 gain/bias 设计动机 |
| 普通 Transformer 里 scale/shift 是固定学好的常数 | ✅ | 每层的 elementwise affine 参数，训练后固定 |

## AdaLN 页

| 表述 | 核查 | 出处 |
|---|---|---|
| AdaLN 区别：参数由 t 生成 + 多一个 gate | ✅ | DiT (adaLN-Zero) 设计；H3 同 |
| gate：输出 = 原有信息 + gate × 子层新信息 | ✅ | h3_model.py block：x = x + gate·attn(...)、x = x + gate·ffn(...) |
| t 不拼进序列，AdaLN 是 t 信息唯一显式注入通道 | ✅ | h3_model.py forward：timestep 只进 time_embedder→temb→AdaLN/norm_out，不进 token 流 |
| 每子层 3 参数 × 2 子层 = 6 组 | ✅ | norm1/norm2 各配 (scale, shift, gate) |

## Q&A 备忘（观众可能会问）

**Q：为什么 9 格，不是 8 组 t？** 表是"本步"的：每步去重 t 只有 3 个，3×3=9；
8 是总步数，每步一张新表——预计算就是把 8 张表提前全算完。

**Q：为什么每格 6 组不是 3 组？** 一层两个子层（attention、FFN），各一套
scale/shift/gate，3×2=6。

**Q：scale/shift 为什么也要随 t 变？** ① t 不拼进序列，AdaLN 是 t 的唯一注入
通道；② 各阶段输入分布不同（噪声↔成品），归一化后要恢复的目标随阶段变。

**Q：attention 和 FFN 里是不是没有 t？"整个 DiT 只有 AdaLN 有 t"对吗？**
对。h3_model.py forward 里 timestep 唯一去向：正弦编码 → time_embedder → temb
→ AdaLN 调制 + norm_out（出口最终归一化，也只按 t）。attention/FFN 权重固定、
公式里无 t，只被间接影响（输入被 scale/shift 调过、输出被 gate 加权）。
背景：DiT 原论文消融过"把 t 当 token 拼进序列"（in-context conditioning），
adaLN-Zero 胜出，主流沿用。⚠️ 第四期位置坐标 (t,h,w) 里的 t 轴是时间位置，
与噪声水平 t 同字母不同物（第四期口播里专门点破了）。

## 有意简化

1. H3 实际用 RMSNorm（不减均值），口播按 LN 通式讲，定性不变。
2. norm_out（最终归一化）只按 t 调制、不分模态——口播未提，不影响主线。
3. "三行"= 本步去重 t 数，示例恰为 3；没说死永远三行。
